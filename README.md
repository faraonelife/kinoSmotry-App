**KinoSmotry** — нативное приложение для просмотра фильмов, сериалов, мультфильмов и аниме с HDrezka.
Без браузера, всплывающих окон и рекламы: открыл, нашёл, смотришь. Одно приложение — на телефоне,
телевизоре и ноутбуке, с общим аккаунтом, закладками и историей.

<details>
<summary><b>🍏 Mac пишет «приложение повреждено» или «не удаётся проверить разработчика»</b></summary>

<br>

Приложение не подписано сертификатом Apple — это нормально для сборок вне App Store.
Нажмите на KinoSmotry в «Программах» правой кнопкой → **Открыть** → **Открыть**.
Или одной командой в Терминале:

```bash
xattr -dr com.apple.quarantine /Applications/KinoSmotry.app
```
</details>

<details>
<summary><b>📱 iPhone: почему приложение перестало открываться через неделю</b></summary>

<br>

С бесплатным Apple ID подпись действует 7 дней. Переустановите .ipa через Sideloadly —
закладки и история сохранятся. AltStore продлевает подпись сам, когда iPhone и компьютер в одной Wi-Fi сети.
</details>

<details>
<summary><b>🔑 Нужен ли аккаунт HDrezka?</b></summary>

<br>

Смотреть можно и без него. Вход в аккаунт сайта добавляет закладки, «Досмотреть» с других устройств
и уведомления о новых сериях. Для премиум-аккаунта доступно высокое качество, как на сайте.
</details>

<details>
<summary><b>🌐 Ничего не грузится</b></summary>

<br>

Скорее всего, основной адрес сайта у вас недоступен. Откройте **Настройки → Зеркало сайта**,
укажите рабочее зеркало и нажмите «Сохранить» — приложение сразу проверит его.
</details>
